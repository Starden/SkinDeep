# SkinDeep

**Damage skins for the floating combat numbers in World of Warcraft: Forever.**

SkinDeep replaces the numbers that pop over your enemies with animated, themed
"damage skins": custom fonts, motion, colors, crit bursts and particles. It ships
with 143 skins, including one for every class, talent tree and race, eleven faction
skins, nineteen PvP skins (up to Grand Marshal and High Warlord), seasonal skins,
twenty anime-inspired skins, and a slot-machine skin that rolls every hit and
hits the JACKPOT on crits.

Type `/skindeep` to open the skin picker with a live preview.

Download: [CurseForge](https://www.curseforge.com/wow/addons/skindeep) (WoW: Forever).

## Collect them, or have them all

The first time you log in, SkinDeep asks how you want your skins:

- **Collector**: start with Classic+, Auto and your class's skin, and earn the
  rest through SkinDeep's own feats (777 crits for Jackpot, Fire damage for
  Ember Tide, a level 10 character of a class for its skin...).
- **Everything unlocked**: every skin right away; feats still pop up for fun.

Switch any time on the **Feats** tab (`/skindeep feats`), which also shows your
progress. Unlocks are shared by all your characters.

## Rotation

The **Rotation** tab (`/skindeep rotate`) lets your skins change by themselves:

- **Random each fight**: a new skin every time combat starts, never the same
  one twice in a row.
- **Cycle**: the next skin every few minutes (1 to 120), changing between
  fights.
- **By zone**: a skin for dungeons, raids, cities and inns, and the open world.
- **By enemy**: a skin for each creature type you hit (Undead, Demon,
  Dragonkin...). The first time you turn it on, fitting skins you own are
  filled in, such as Chain Rev for Demons and Steam Blades for Giants.

It rotates through every skin you've unlocked, or only the ones you pick:
Ctrl-click skins in the list. Which skin a hit gets: your PvP skin first, then
the enemy's, then the zone's, then the rotation, then the skin you chose.

## Colors

Physical and spell damage always read apart, like Blizzard's white and yellow:

- **Skin palette**: each skin's own pair (physical paler, spell stronger).
- **Classic**: physical white, spell yellow on every skin.
- **Spell schools**: Fire orange, Frost blue, Shadow purple and so on.

## Options

`/skindeep` (or the addon compartment button) opens the settings window:

- **Numbers**: replace Blizzard's numbers, show both, or only restyle Blizzard's
  (their font and motion).
- Enemy nameplates (AoE), damage you take, heals you receive.
- Bursts and particles, skin sounds, abbreviated big numbers, size and speed.
- **Blizzard's numbers in groups**: off by default. See *Groups* below.

Slash commands: `/skindeep test`, `/skindeep feats`, `/skindeep list`,
`/skindeep skin <name>`, `/skindeep welcome`, `/skindeep on`, `/skindeep off`,
`/skindeep restore`, `/skindeep unlock`, `/skindeep peek [name]`, `/skindeep pvp`,
`/skindeep rank`, `/skindeep talents`, `/skindeep loot`,
`/skindeep rotate [off | fight | cycle <minutes>]`, `/skindeep zone <place> <skin | off>`,
`/skindeep enemy <type> <skin | off>`.

## Good to know

- **Groups:** the game doesn't tell addons whose hit landed on your target, so in
  a party SkinDeep also shows your party's hits on your target. Tick
  *Blizzard's numbers in groups* to hand back to Blizzard's numbers (which only
  show yours) while grouped.
- **Hidden amounts:** WoW: Forever hides damage amounts from addons in combat.
  Addons can show them but not read them, so effects like Jackpot's rolling reels
  spin random numbers before landing on the real hit.
- **Blizzard's font** changes at your next login (the game reads it once).
- **Uninstalling:** SkinDeep hands back every game setting it changes each time
  you log out. `/skindeep restore` does it on the spot.

## Development

The shipped addon is the Lua files, `SkinDeep.toc` and `Media/`. Everything else
is tooling (needs Node.js):

```bash
npm install
npm test               # Lua syntax check + mock-client test suite
npm run assets         # regenerate fonts, textures and the logo
npm run gallery        # render every skin into tools/gallery (add skin ids to render only those)
npm run serve          # serve the gallery on http://localhost:5177
npm run audit          # score every skin against the quality bar
npm run similar        # list the skins that look most alike
npm run install-addon  # copy the addon into your WoW: Forever AddOns folder (Windows)
```

- `tools/make_fonts.js` and `tools/make_textures.js` generate all fonts and
  textures from code, so every asset is original and MIT-licensed.
- `tests/` runs the addon in a Lua VM against a mocked WoW API, including
  secret (unreadable) combat values.
- `npm run gallery -- rogue mage` renders only those skins; `npm run similar
  -- --top 10` and `npm run audit -- --json` pass options through.
- `npm run install-addon` copies to `D:\World of Warcraft\_forever_\Interface\AddOns`
  and deletes installed files the repo no longer has; for another folder, run
  `tools/install.ps1 -AddOns "<path>"`.

Releases: pushing a tag like `v1.2.0` runs the tests, then the
[BigWigs packager](https://github.com/BigWigsMods/packager) builds the zip and
uploads it to CurseForge and GitHub (see `.github/workflows/release.yml`).
